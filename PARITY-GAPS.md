# Sciter ⇄ Flutter parity gaps (open list)

Hand-maintained, both directions, presence AND behaviour. The rule that feeds it is in the
workspace `AGENTS.md` ("Sciter ⇄ Flutter parity check"): every client task checks the other UI
and either fixes the gap in the same change or adds a row here. Close a row by moving it to
**Closed** with the commit that fixed it.

`FLUTTER-PARITY-ELEMENTS.md` (generated by `tests/parity/inventory.py`) covers only
Sciter -> Flutter presence; this file is for everything it cannot see.

Direction: **F→S** = Flutter has it, Sciter lacks/differs; **S→F** = the reverse;
**both** = missing or broken in both.
